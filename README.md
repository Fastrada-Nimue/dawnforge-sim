# Dawnforge Sim

Browser-based defense roguelite prototype.

## Share Online (Best Option: GitHub Pages)

This project is already configured to auto-deploy to GitHub Pages using:
`/.github/workflows/deploy-pages.yml`

Do this once:

1. Create a new GitHub repository.
2. Push this `dawnforge-sim` folder to the `main` branch.
3. In GitHub: `Settings -> Pages`.
4. Under `Build and deployment`, set `Source` to `GitHub Actions`.
5. Wait for the `Deploy Dawnforge To Pages` workflow to finish.

Your game URL will be:
`https://<your-github-username>.github.io/<repo-name>/`

## Local Play

Open directly in your browser:
`index.html`

For pop-out mode:
`index.html?popout=1`
